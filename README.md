# ⚽ Zona 7 - Liga de Fútbol

Plataforma web para la gestión de una liga de fútbol 7.

## 🚀 Funcionalidades

- 📅 Fixture dinámico
- 🏆 Tabla de posiciones automática
- 📊 Estadísticas en tiempo real
- 🧑‍💻 Panel de administración de resultados
- 🔄 Actualización en vivo con Supabase

## 🛠️ Tecnologías

- React + Vite
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
